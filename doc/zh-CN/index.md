# 显示规则

[English](../manual/index.md) · [文档目录](../README.md)

本版有两套独立的标记。

## 顾客需求框

是否需要某件物品仍由顾客接受规则决定。匹配物品使用实线框，可带淡底色；框色只由选中的物品类型决定。同类型的普通、赃物和违禁商品使用相同框色与线型。

容器本体不匹配、内容物匹配时，使用统一颜色的四角提示。机器储物标签页也使用这种颜色和角标。容器本体被接受时，按自身物品类型画完整框。

顾客需求保留上游对上锁、锁后物品、不可移动物品、整箱收购、以物易物、多样化和灵活买家的处理。灵活买家选定需求后才开始标记。手动筛选有独立规则，可以忽略锁。

治安官盘查不会额外生成按法律属性上色的框线；属性由常驻星标表达。

## 永久属性星标

| 物品本体属性 | 默认星标 |
| --- | --- |
| 两种属性都没有 | 不显示 |
| 仅赃物 | 黄色 |
| 仅违禁品 | 绿色 |
| 同时为赃物和违禁品 | 一颗红星 |

原生 `GameItemElement` 视图创建或刷新时会独立注册，覆盖仓库以外的柜台、顾客商品、展示柜、容器、机器和其他场景中的原生物品视图。没有顾客、关闭需求框时也会检查和显示。

容器只显示自身的星标，不会把内容物属性合并到箱子本体。像素星挂在物品外层界面的右上角，避开内部旋转层，不接收点击、不参与布局。真实游戏中的旋转、翻转、裁切仍需验证。

## 设置和兼容

所有标记颜色、类型优先级、圆角、粗细、底色、星标倍率和内边距均可设置，见[配置](configuration.md)。

请停用原 Demand Highlight 和其他重叠标记 Mod。独立 Mod ID 不等于支持同时启用两个查询 API 提供者；本版保留了原有 API 契约。当前是源码状态，真实游戏构建条件见[构建与安装](building.md)。
